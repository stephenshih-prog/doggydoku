# Doggydoku

每一列、每一行、每一塊草皮，都只住一隻狗狗。

一個用瀏覽器就能玩的邏輯解謎小遊戲：60 關闖關（5×5 到 9×9），加上每天一題。

## 怎麼玩

- 每一列、每一行、每一塊顏色草皮，都剛好藏著一隻狗狗。
- 兩隻狗不能相鄰，斜角也不行。
- 點一下打叉，快速連點兩下放狗狗。猜錯扣一顆心，三顆扣完重來。

進度存在你自己的瀏覽器裡，不會上傳到任何地方。

過關後會隨機播放 5 種狗狗慶祝動畫之一，5 秒後顯示成績。可按「略過，下一關」直接繼續；每日一題與最後一關則顯示成績。動畫支援系統的減少動態效果設定，並沿用既有過關音效與聲音開關。

## 檔案

整個遊戲就是一個 `index.html`，沒有建置步驟，直接用瀏覽器打開就能玩。

## 開發測試

使用 Node.js 20.19+（或 22.12+、24+），執行 `npm ci` 後執行 `npm test`。
測試涵蓋關卡唯一解，以及過關、失敗返回與暫停恢復流程。
測試依賴僅供開發使用；遊戲仍可直接開啟 `index.html`，不需建置。
